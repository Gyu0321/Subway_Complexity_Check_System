# Subway_Complexity_Check_System
# 지하철 복잡도 확인 시스템

본 프로젝트는 지하철의 인구 수를 API로 받아와 해당 지하철의 복잡도를 확인하는 시스템을 구성한 프로젝트입니다.

## 주요 기능
- 호선, 상하선, 역이름 정보를 입력하면 현재 시간과 가장 가까운 시간대에서의 지하철 혼잡도를 출력합니다.
- 자주 검색하는 역의 정보를 저장하는 기능을 지원합니다.
- 전에 저장된 역의 정보를 불러오는 기능을 지원합니다.

## 기술 스택
- Server Socket
- API
- GUI

## 설치 방법
- GITHUB 파일 다운 후 Gui.java에서 서버소켓 작동 후 따로 저장된 클라이언트 파일에서 Client.java를 실행하면 서버소켓에 접속하여 프로젝트를 실행할 수 있습니다.

## 참고사안
- gson-2.13.2를 사용했습니다.위치:(C드라이브)
